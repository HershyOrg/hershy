# shared/components

Reusable UI components that are not tied to one feature.

Examples:
- `AppHeader`: app shell/header component
- `Button`: reusable button wrapper with existing style variants
- `ToggleGroup`: segmented control for mode switches
- Generic modals and sidebars when they are needed
- Empty/loading states that are shared across multiple features

Feature-specific cards, vault panels, or strategy graphs should stay in the feature folder.
