# shared

Shared frontend code used by multiple features or pages.

- `components`: Shared React components. `ui` contains the base shadcn-based UI components.
- `hooks`: Shared React hooks.
- `api`: Browser-side API client area. `dummyApi.ts` currently provides screen data without a backend.
- `store`: App-wide browser state stores.
- `types`: Type definitions shared across features.
- `utils`: Pure utility functions.
- `constants`: Shared constants.
- `mock-data`: Demo data shared across multiple areas.
