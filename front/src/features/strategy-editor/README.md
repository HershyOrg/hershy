# strategy-editor

Feature code for the strategy canvas and node editor.

- `components`: Node, edge, toolbar, and canvas UI components.
- `store`: State stores for strategy execution, history, and metadata.
- `types`: Node and graph editor types.
- `utils`: Pure logic for graph transforms, layout, condition brackets, and related behavior.
- `mock-data`: Demo strategies and Binance demo data used by the strategy editor.
- `api`: Placeholder for a strategy-editor-specific API client. The shared dummy API currently lives in `shared/api`.
- `hooks`: Placeholder for strategy-editor-specific hooks.
