# ai-wallet

A plain Vite + React frontend app for the Hershy wallet wrapper MVP.

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Runs TypeScript checks and the Vite production build.
- `npm run start`: Previews the build output with Vite preview.

The app intentionally uses frontend dummy data. Replace the functions in `src/shared/api/dummyApi.ts` when connecting the backend.
