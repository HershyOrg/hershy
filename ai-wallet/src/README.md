# src

Root directory for the frontend application code.

- `shared`: Reusable API helpers, components, types, utilities, and browser-facing code used across screens and features.
- `features`: UI, state, mock data, and utility code grouped by feature.
- `pages`: Route-level screen components.
- `main.tsx`: Entry file that mounts the React app into the DOM.
- `App.tsx`: App wrapper that connects page components.
